バーの「**再生中の曲**」を作り直し、サムネイル・動く波形・再生位置をバーに出せるようになりました。あわせて、タスクバーの見た目の細かい改善と、**長く動かしてもメモリが増えにくくなる自動の後片付け**を入れました。

## 新機能

### 再生中の曲ウィジェットの作り直し
- **サムネイル**（曲のジャケット・動画の画像）をバーの高さいっぱいに表示します。
- **動く波形**: 再生中だけ、サムネイルの中で 3 本の棒が動きます。一時停止で止まります。
- **再生位置**: 曲名の下に、直線または**波線**（再生中は波がゆっくり流れ、先頭に現在位置の丸が付きます）で出します。
- **リング型**: 再生位置の輪で囲んだ丸いサムネイル（文字なし）。**縦のバー**では、幅に収まるよう、常にこの形になります。
- **ライブ配信**（Twitch など、長さの無いもの）は、再生位置の代わりに **LIVE** と表示します。
- 設定の「ウィジェット」ページ →「再生中の曲の見た目」で、形・サムネイル・波形・再生位置・線の形・曲名の最大幅を選べます。低いバーでは、サムネイルを小さくし、曲名とアーティストを 1 行にまとめます。
- **クリックでポップアップ**が開きます（ジャケット・曲名・シークバー・前の曲 / 再生・一時停止 / 次の曲）。**再生中のものが複数あれば、全部**並べて操作できます。
- バーには、再生中のものを優先して表示します（一時停止中のものが選ばれにくくなります）。

### ウィンドウのプレビューでメディア操作
- 音楽や動画を再生中のアプリのボタンにカーソルを置くと、プレビューの下に曲名と「前の曲・再生 / 一時停止・次の曲」が出ます（設定でオフにできます）。

### ウィンドウ数の点
- 同じアプリのウィンドウが複数あると、実行中の印が、ウィンドウの数（最大 3）だけ並びます。

### 壁紙に合わせたバーの色
- バーの色に「**壁紙**」を追加しました。壁紙の平均色をテーマの色と混ぜます。壁紙を変えると自動で追従します。

### 自動非表示の細線
- バーを自動で隠している間、画面の端に細い線を残します。区切りは開いているアプリで、前面のアプリはアクセント色です。クリックは素通しで、全画面のアプリの間は出ません（設定でオフにできます）。

## 改善

### メモリ
- 操作の無い間に、使っていないメモリを自動で OS に返します（10 分ごとに確認し、1 分以上操作が無く、使用量が増えているときだけ）。長時間動かしても増え続けにくくなります。
- 設定画面を閉じたあとの整理を強化しました。設定を開いたあとも、起動直後に近い使用量に戻ります。
- デバッグログがオフのときは、ログ専用の重い調べものを省くようにしました。

## 変更点
- バーの「再生中の曲」は、**クリックでポップアップ**が開くようになりました（以前は、クリックで再生 / 一時停止）。再生 / 一時停止は、ポップアップのボタンと、右クリックのメニューにあります。

## 既知の制限
- ブラウザーは、複数のタブで再生していると、情報を 1 つにまとめて渡します。そのため、タブごとには区別できません。
- 一部の動画（YouTube など）では、ブラウザーが再生位置を報告しない間があります（一時停止・再生・シークなどで出ます）。その間は、薄い線だけを出します。

## アップデート方法
ModernShell を終了して（トレイの ModernShell アイコン →「純正タスクバーに戻して終了」）、新しいファイルに置き換えるだけです。設定はそのまま引き継がれます。

## 困ったときは
- **Ctrl + Alt + Shift + F12** で、いつでも終了して純正に戻せます。
- 万一タスクバーが隠れたままになったら、`ModernShell.exe --restore` を実行してください。
- 設定とログ：`%AppData%\ModernShell`
