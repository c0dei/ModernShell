バーの機能が「ウィジェット」として大きく増え、設定画面もリデザインされました。

## 新機能
- **ウィジェットの追加**: 音量・ネットワーク（Wi-Fi の詳細）・ネットワーク速度（30 秒の履歴）・CPU/メモリ・カレンダー（月表示と予定）・時計（4 つの表示）・通知（アプリごとのポップアップ、おやすみモード連動）・IME 表示・タスク ビュー・検索・Everything を、バーのウィジェットとして追加できます。
- **トレイ アイコンをウィジェット化**: あふれたアイコンのポップアップでは、ドラッグで並べ替え（順序は保存）、バーへのドロップができます。
- **タスクバーのフォルダー**: バーの右クリックから追加でき、グリッド / スタック表示と編集モードがあります。
- **ウィジェットの操作**: ドラッグで並べ替えや位置の移動、右クリックのメニューから個別設定ができます。
- **通知のクリック**: 通知をクリックすると、対応するアプリ・URL・設定ページが開きます。

## 改善
- 設定画面をリデザインしました（各ページに説明文・アイコン・折りたたみグループ・ライブプレビュー）。
- 再生中の曲ウィジェットのデザインを見直し、メディアイベントで即時に更新するようにしました。
- ポップアップに閉じるアニメーションを付け、バーの色と角丸を反映しました。
- タスクバーの高さとアイコンの大きさを 3 段階のプリセット（40 / 44 / 48 px）にしました。
- マルチモニターで、すべてのバーに実行中のアプリを同じ順序で表示します。
- 細いスクロールバーをアプリ全体で使うようにしました。

## 変更点
- バー内蔵の「クイック設定」ボタンを削除しました。
- 管理者権限で動作中は、ユーザーが書き込める場所の Everything を信用せず、通常の権限で起動します。

## アップデート方法
ModernShell を終了して（トレイの ModernShell アイコン →「純正タスクバーに戻して終了」）、新しいファイルに置き換えるだけです。設定はそのまま引き継がれます。

## 困ったときは
- **Ctrl + Alt + Shift + F12** で、いつでも終了して純正に戻せます。
