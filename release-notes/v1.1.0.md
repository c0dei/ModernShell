タスクバーを**上下左右の好きな端**に置けるようになり、**管理者として動くアプリ**（管理者の Terminal など）でも IME の表示や Win キーが効くようになりました。

## 新機能

### タスクバーを上下左右に置ける
- 「画面上の位置」が 下 / 上 / **左 / 右** の 4 択になりました。左・右にすると縦向きのタスクバーになります。
- 縦向きでは、スタート・アプリ・トレイのボタンが縦に並び、アイランドも縦に伸び縮みします。細いバーでは、時計が「時」「分」の 2 段表示になります。
- メニュー・ウィンドウのプレビュー・「^」の一覧・スタートメニューは、バーの隣（画面の内側）に開きます。

### 余白を左右・上下で別々に設定
- 帯・アイランドそれぞれに「余白（左右）」と「余白（上下）」を用意しました（0 / 4 / 8 / 12 / 16 / 24 px）。以前の設定は引き継がれます。

### 管理者として起動
- 一般 →「管理者として起動する」をオンにすると、サインイン時にタスクスケジューラ経由で管理者として自動起動します（毎回の UAC の確認は出ません）。
- **管理者として動いているアプリ**（管理者の Windows Terminal など）でも、IME の表示・Win キー・キー操作・トレイアイコンが効きます。
- ModernShell から開いたアプリは、管理者で動いていても**普通の権限で起動**します（「管理者として実行」を選んだときだけ管理者）。

## 改善

### IME の表示
- 入力欄が別のウィンドウになっているアプリ（秀丸・Excel など）でも、正しく表示されるようになりました。
- IME の状態を問い合わせても答えないアプリ（Windows Terminal など）では、半角/全角・漢字キーなどの操作から、オン/オフを推測して表示します。IME の表示をクリックしたときも、同様に切り替えられます。
- 管理者のアプリが前面のときは、ModernShell を管理者で動かすと正しく読み取れます。

## 修正
- 白い枠（アイコンの台紙）が付いていたスタートメニューのアイコンを、タスクバーと同じ取り出し方に統一しました（v1.0.1 からの継続）。
- 縦向きのタスクバーで、時計の処理の失敗によりバーが表示されなくなる不具合を修正しました。組み立ての途中で失敗しても、バーは必ず表示されます。

## アップデート方法
ModernShell を終了して（トレイの ModernShell アイコン →「純正タスクバーに戻して終了」）、新しいファイルに置き換えるだけです。設定はそのまま引き継がれます。

## 困ったときは
- **Ctrl + Alt + Shift + F12** で、いつでも終了して純正に戻せます。
- 万一タスクバーが隠れたままになったら、`ModernShell.exe --restore` を実行してください。
- 設定とログ：`%AppData%\ModernShell`
